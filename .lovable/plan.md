## Goal
Emerald POS ko do platforms pe chalayen:
- **PC (Windows .exe)** — Electron wrapper
- **Mobile (Android .apk)** — Capacitor wrapper

Dono mein **thermal printer instant print** (58mm/80mm ESC/POS) aur baaki POS features (jo already hain) kaam karen — offline, localStorage based.

---

## Deliverables

1. **Web app upgrades** (shared by exe + apk)
   - Thermal receipt renderer (ESC/POS commands: header, items, totals, QR, cut)
   - Printer settings screen: paper width (58/80mm), header text, footer text, printer connection type
   - "Print" button on receipt uses native bridge if available, warna browser print fallback
   - Offline-first (already localStorage)
   - Barcode/qty keypad friendly for tablet
   - Daily sales report export (CSV to `/mnt/documents` on desktop, share sheet on Android)

2. **Desktop (Electron → .exe source)**
   - `electron/main.cjs` + preload
   - Thermal print via **USB/Network ESC/POS** using `node-thermal-printer` (USB, Serial, or TCP)
   - IPC channel `print-receipt` from renderer → main
   - Build script: `@electron/packager` for Windows target
   - Vite `base: './'` fix
   - Produces source + build command for `.exe`

3. **Mobile (Capacitor → .apk source)**
   - Add Capacitor (android platform)
   - **Bluetooth thermal printer** plugin (`@capacitor-community/bluetooth-le` + ESC/POS byte builder) — pair, select, print
   - Permissions in `AndroidManifest.xml` (Bluetooth, Location for BLE)
   - Splash + icon (Emerald theme)
   - Build script: `npx cap sync android` → Gradle `assembleDebug` for `.apk`

4. **Docs**
   - `BUILD.md` explaining how to run:
     - `npm run build:exe` (Windows)
     - `npm run build:apk` (Android)
   - Printer setup instructions (USB vs Bluetooth vs Network)

---

## Technical notes

- Sandbox mein `.exe` cross-compile Wine ke bina reliably nahi banti; hum **source + one-command build script** dete hain jo user apni Windows machine ya CI pe chala k `.exe` bana lega. Linux `.tar.gz` demo build sandbox mein bana ke verify karenge.
- APK: Android SDK sandbox mein nahi hai; source + `gradlew assembleDebug` command denge. User Android Studio ya CI se APK generate karega.
- Thermal print detection: `window.electronAPI?.printReceipt(...)` (desktop), `window.Capacitor?.isNativePlatform()` → BLE flow (mobile), else browser `window.print()`.
