# Emerald POS — Desktop (.exe) & Android (.apk) build guide

The web app in this repo works standalone. To ship it as a **Windows desktop
program** and a **native Android app** with **thermal-printer support**, follow
the steps below on your local machine.

> The Lovable sandbox cannot cross-compile Windows `.exe` files or Android
> `.apk` files — those need the Windows/Android toolchains installed locally.
> Everything else (source code, packaging scripts, printer bridge) is ready.

---

## 1. Local prerequisites

| Target | Install |
| --- | --- |
| Windows `.exe` | Node 20+, Git, Windows 10/11 |
| Android `.apk` | Node 20+, Android Studio + JDK 17, Android SDK 34 |

```bash
git clone <this repo>
cd emerald-pos
npm install
```

---

## 2. Windows desktop (`.exe`)

Uses **Electron** + **@electron/packager**. Thermal printing goes through
`node-thermal-printer` over USB or raw TCP (ESC/POS on port 9100).

```bash
npm install --save-dev electron @electron/packager
npm install node-thermal-printer          # only needed for USB printers

# Build the web bundle + package
npm run build
npx @electron/packager . "EmeraldPOS" \
  --platform=win32 --arch=x64 \
  --out=electron-release --overwrite \
  --ignore="^/src" --ignore="^/public" \
  --ignore="^/android" --ignore="^/electron-release"
```

The `EmeraldPOS-win32-x64/` folder contains `EmeraldPOS.exe`. Zip it and
distribute, or wrap it with an installer (Inno Setup / NSIS) if you want a
setup wizard.

### Printer options on desktop
Open **Printer Settings** in the app header:
- **Network (LAN)** — enter the printer IP (e.g. `192.168.1.50`) and port
  `9100`. Works with almost every 58/80 mm receipt printer that speaks
  ESC/POS.
- **USB** — enter the USB Vendor/Product IDs (find them in Device Manager).
- **Browser print** — falls back to the OS print dialog.

## 3. Android app (`.apk`)

Uses **Capacitor**. Thermal printing goes through **Bluetooth LE** to any
common ESC/POS printer (MTP-II, GOOJPRT, RPP, etc.).

```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npm install @capacitor-community/bluetooth-le

npm run build
npx cap add android
npx cap sync android

# Debug APK
cd android
./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk

# Signed release APK (needs a keystore)
./gradlew assembleRelease
```

Before building, add these permissions to `android/app/src/main/AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.BLUETOOTH" />
<uses-permission android:name="android.permission.BLUETOOTH_ADMIN" />
<uses-permission android:name="android.permission.BLUETOOTH_SCAN"
    android:usesPermissionFlags="neverForLocation" />
<uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
```

Install the APK: `adb install app-debug.apk` or transfer to the device.

### Printer pairing on Android
1. Pair the thermal printer in Android's Bluetooth settings.
2. Open Emerald POS → **Printer Settings** → set connection to
   **Bluetooth**, optionally type the printer name prefix.
3. First print will prompt device selection; the choice is remembered.

## 4. How the print bridge works

Same code path in every platform:

```
Receipt "Print" button
        │
        ▼
  src/lib/printer.ts  ← detects platform
        │
        ├── Electron  → window.electronAPI.printReceipt(bytes, settings)
        │              → electron/main.cjs → USB / TCP:9100
        │
        ├── Capacitor → src/lib/printer-bluetooth.ts → BLE write
        │
        └── Browser   → opens print window (monospace receipt)
```

Receipt bytes are generated by `src/lib/escpos.ts` (58 mm = 32 cols,
80 mm = 48 cols; bold total, partial cut).

## 5. Vite base path

`vite.config.ts` must produce relative asset URLs for Electron and Capacitor
(they load over `file://` / `capacitor://`). This project already sets
`vite: { base: './' }`.
